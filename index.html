The shortest possible workflow

Sign in. Click. Know.

There is no separate account system to configure. The extension uses the Ollama session Chrome already has, fetches the account usage page, parses it locally, and gives you the useful numbers.

Privacy by smallness

Nothing extra in the middle.

The extension talks only to Ollama’s own settings page. Parsing happens locally inside the extension. There is no hosted dashboard, analytics service, advertising layer or external backend.

01
No password collectionThe extension uses the Ollama login session already managed by Chrome.
02
No cookie copyingIt does not read or save the Ollama session cookie into extension storage.
03
No analytics or telemetryNo usage tracking, ads, third-party services or hidden reporting pipeline.
04
Local fallback onlyThe latest parsed display values may be cached locally for up to 24 hours to survive a temporary network failure.
05
Readable sourceThe implementation, permissions and privacy statement are all visible in the public repository.
Install // developer mode

From repo to toolbar in about a minute.

The extension is ready to load directly as an unpacked Chrome extension. No build step. No npm install.

chrome://extensionsDEVELOPER MODE
Developer mode
Load unpacked↗
Pin extension◐
  1. Download or clone staffordlumsden/ollama-cloud-usage-extension.
  2. Sign in to ollama.com in Chrome.
  3. Open chrome://extensions and enable Developer mode.
  4. Choose Load unpacked and select the extension folder.
  5. Pin Ollama Cloud Usage to the toolbar.
Get the extension →Read install notes
Requires Chrome 109+ and an Ollama account. Ollama Cloud Usage is an independent open-source extension and is not presented as an official Ollama product.
