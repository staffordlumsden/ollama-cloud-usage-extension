How it works

Already signed in? You’re basically done.

The extension uses the Ollama session already managed by Chrome. Open the popup and it reads the same account usage information you would otherwise visit Ollama Settings to see.

01 / SIGN IN

Use Ollama normally

Sign in to ollama.com in the same Chrome profile where the extension is installed.

02 / CLICK

Open the toolbar popup

Pin Ollama Cloud Usage, click once, and the extension fetches your current account usage page.

03 / GLANCE

See what matters

Session percentage, 5-hour reset, weekly percentage, weekly reset, plan details and models used are surfaced immediately.

What you get

A tiny popup with the information you actually came for.

No dashboard-within-a-dashboard. Just the useful account signals, designed for people who regularly use Ollama Cloud models.

[ 5H ]

Session usage + reset

See how much of the current five-hour window you have used and how long remains until it resets.

[ 7D ]

Weekly usage + reset

Keep an eye on the longer usage window without repeatedly navigating through Ollama account pages.

[ MODELS ]

Models used this week

View the cloud models used during the weekly window, together with request counts.

[ CACHE ]

Graceful temporary fallback

The most recent parsed usage snapshot can be shown as clearly marked stale data during a temporary network failure, for up to 24 hours.

Privacy by construction

There is nowhere for your data to go.

The extension does not operate a hosted service. It requests the signed-in Ollama settings page, parses it locally in the popup, and keeps only a short-lived local fallback snapshot.

Install

Load it into Chrome in about a minute.

The repository is ready to load directly as an unpacked Manifest V3 extension. There is no build step and no npm install required.

LOCAL INSTALL
  1. Download or clone staffordlumsden/ollama-cloud-usage-extension.
  2. Sign in to ollama.com in Chrome.
  3. Open chrome://extensions.
  4. Turn on Developer mode.
  5. Choose Load unpacked and select the extension folder.
  6. Pin Ollama Cloud Usage to the toolbar.
